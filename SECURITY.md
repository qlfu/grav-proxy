# Безопасность и приватность

**Русский** · [English](./SECURITY.en.md)

## Открытый код и отсутствие телеметрии

Весь исходный код `GravProxy` начиная с `v2.0.0` полностью открыт в репозитории `qlfu/grav-proxy` и собирается из чистого Go (`CGO_ENABLED=0`) + Wails v2 без сторонних пакеров, шифрованных контейнеров, телеметрии, зашитых VLESS-ключей, ссылок на подписки и API-ключей.

Все пользовательские параметры хранятся исключительно локально на устройстве:

- Основная конфигурация (`mode`, `endpointUrl`, `subscriptionUrl`, `smartDnsUrl`, компоненты) — в `%LOCALAPPDATA%\GravProxy\config.json` (устаревшие `AG_PROXY_VLESS` / `AG_PROXY_SUB_URL` из `v1.x` могут считываться при миграции и удаляются при деинсталляции).
- Токен локального HTTP control-API (`/_ctl/status`, `/_ctl/toggle`, `/_ctl/reload`, `/_ctl/recheck`, `/_ctl/stop` на `127.0.0.1:28081`, заголовок `X-GravProxy-Token`) — в `%LOCALAPPDATA%\GravProxy\control.token` (случайные 128 бит, генерируются локально).
- Профиль `3p` и API-ключи Claude Desktop — в `%LOCALAPPDATA%\Claude-3p\configLibrary\` (включая VFS-каталог MSIX `Packages\Claude_*\LocalCache\Local\Claude-3p`).

## Проверка целостности (`GravProxy.exe`)

Перед запуском готового релиза сверяйте контрольную сумму:

```powershell
Get-FileHash .\GravProxy.exe -Algorithm SHA256
```

Актуальная сумма `v2.0.0`: `8A0253712D29F45E1FB0374EB7E5D194ADA83BFF4D6F2434EA69F10130F522E7` (см. также [Releases](https://github.com/qlfu/grav-proxy/releases/latest)). Встроенный автообновитель проверяет HTTPS-домен GitHub, заголовок `PE/EXE` (`MZ`) и совпадение `SHA-256` перед заменой бинарника.

При желании вы можете собрать идентичный бинарник самостоятельно из этого репозитория (см. раздел «Сборка из исходников» в [README.md](./README.md)) или скачать артефакт GitHub Actions.

## SmartScreen и ложные срабатывания антивирусов

- `GravProxy.exe` не подписан коммерческим сертификатом EV/Authenticode, поэтому Windows SmartScreen может показать предупреждение *«Система Windows защитила ваш компьютер»* — нажмите **«Подробнее» → «Выполнить в любом случае»** после сверки `SHA-256`.
- Начиная с `v2.0.0` бинарник больше **не содержит** SFX-распаковки во временные каталоги, скриптов PowerShell или компиляции C# через `csc.exe`, поэтому вероятность ложных срабатываний минимальна. Если конкретный AV всё же отреагирует на запись автозапуска `HKCU\...\Run` или патч локальных `.exe`, добавьте `GravProxy.exe` и `%LOCALAPPDATA%\GravProxy` в исключения после проверки `SHA-256`.

## Приватность в режиме SmartDNS (без VPN)

При выборе режима `SmartDNS` (`dns.dns-ai.ru`, `eu.geohide.ru`, `us.geohide.ru`, `dns.malw.link`, `dns.commonnet.work` или свой DoH/DoT) корневые сертификаты в систему **не устанавливаются**, а HTTPS-трафик остаётся зашифрованным end-to-end (SNI-прокси не расшифровывает содержимое запросов и ответы). Владелец выбранного SmartDNS-сервера технически видит DNS-запросы, SNI-имена целевых AI-доменов и ваш внешний IP-адрес; остальные сайты идут `DIRECT` через системный DNS.

## Сообщение об уязвимостях

Если вы обнаружили ошибку безопасности, сообщите о ней через **GitHub Security Advisories** или Issues репозитория `qlfu/grav-proxy`. Не прикладывайте к отчётам свои реальные VLESS-ссылки, подписки, API-ключи и содержимое `control.token`.
