# История изменений (`CHANGELOG`)

**Русский** · [English](./CHANGELOG.en.md)

## `v2.0.0` — Открытый исходный код · Go + Wails v2 + встроенный `sing-box`

Полный архитектурный перезапуск проекта на нативном **Go 1.27** (`CGO_ENABLED=0`) с GUI на **Wails v2 (WebView2)** и встроенным в процесс ядром **`sing-box v1.14.4`** без внешних бинарников, без PowerShell/C# и с полностью открытым исходным кодом в репозитории.

- **Единый бинарник без распаковки (`GravProxy.exe`)**:
  - Один файл совмещает все 4 режима: GUI-установщик, службу системного трея (`--tray`), лаунчер приложений (`--launch antigravity|opencode|claude`) и CLI (`--cli status|smartdns-test|test|install|repatch|uninstall`).
  - Автоматический одноэкземплярный запуск GUI (новое окно корректно закрывает старое через `WM_CLOSE` и PID-файл `%TEMP%\gravproxy-gui.pid`, не затрагивая процесс `--tray`).
  - Воспроизводимая сборка из исходников и CI-пайплайн GitHub Actions ([`.github/workflows/release.yml`](./.github/workflows/release.yml)).
- **Новый `SmartDNSRelay` (IP-фильтрация без VPN) + `DNS-AI`**:
  - Локальный UDP DNS-релей на базе `miekg/dns` предварительно пробивает весь пул IP SNI-прокси реальным `TLS + SNI` хендшейком, вырезает заблокированные/чёрнодырные IP на российских провайдерах и кэширует только живые маршруты.
  - Добавлен пресет **`DNS-AI`** (`https://dns.dns-ai.ru/dns-query`), а также обновлены **`GeoHide EU`**, **`GeoHide US`**, **`MalwDNS`** и **`CommonNet`**.
- **Исправления подбора VLESS и скорости прокси**:
  - Добавлен локальный `ipv4_only` резолвер строго на исходящий VLESS/upstream outbound в `sing-box` (убирает 5.1 с задержки на AAAA DNS-запросах без поломки удалённого резолва).
  - Поддержка `cookiejar` при 307/cookie-редиректах подписок.
  - Лимит чтения HTTP-проб увеличен с `256 КБ` до `2 МБ` — фикс распознавания страны на полной 600+ КБ странице `policies.google.com/terms` + параллельный отбор узлов по `Google GeoIP`, `NotebookLM` и `Gemini` (без `/sorry`), а также полноценный VLESS failover/repick в трее с исключением упавшего узла.
- **Аккуратный патч, ноль мигающих консолей и чистое удаление**:
  - Перед патчем, перепатчем и удалением целевые приложения (`Antigravity`, `OpenCode`, `Claude`) корректно закрываются через `StopTargetApps` (без завершения родительского терминала/IDE).
  - Все фоновые команды (`opencode-cli.exe`, `--tray`, `Claude:`, отложенное самоудаление) запускаются с `CREATE_NO_WINDOW`.
  - Исправлен кросс-поточный `Shutdown` Win32-окна трея (`PostMessageW(wmClose)` + идемпотентный `NIM_DELETE`), COM STA для ярлыков (`withWScriptShell` на отдельном OS-потоке), автомиграция каталога `%LOCALAPPDATA%\ag-proxy` -> `%LOCALAPPDATA%\GravProxy`, и полное удаление каталога данных и `AG_PROXY_*` при нажатии **«Удалить»**.

## `v1.7.1`

- **Исправление SmartDNS (`bootstrap: local` + таймаут запуска Defender)**:
  - Заменён `bootstrap`-резолвер в `sing-box` с `https://1.1.1.1/dns-query` на системный `local`, чтобы блокировки Cloudflare `:443` не ломали все DoH-серверы сразу.
  - Увеличен таймаут ожидания старта `sing-box.exe` при подборе SmartDNS (с 6 до 18 сек) и таймауты HTTP-проб (с 5 до 7 сек).
- **Патч `language_server.exe` при запущенном Antigravity**: добавлен перенос заблокированного `.exe` во временный `.old` через `MoveFileExW`.
- **Надёжное автообновление с живым прогрессом и fallback**: потоковая загрузка по 64 КБ с переключением на `127.0.0.1:28080` при скорости ниже 40 КБ/с.
